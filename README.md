# Restful Booker API Tests

Тестовое задание по функциональному тестированию REST API сервиса [Restful Booker](https://restful-booker.herokuapp.com/apidoc/index.html). Проект содержит 57 трассируемых позитивных и негативных тест-кейсов, исполняемую Postman-коллекцию и 9 подтверждённых баг-репортов.

## Состав проекта

| Артефакт | Назначение |
| --- | --- |
| `postman/Restful-Booker.postman_collection.json` | Коллекция Postman v2.1 с проверками во вкладке Tests |
| `postman/Restful-Booker.postman_environment.json` | Публичный base URL и документированные demo credentials |
| `test-cases/Test-cases.xlsx` | Тест-кейсы, результаты исследовательского прогона и матрица покрытия |
| `bug-reports/Bug-reports.xlsx` | Сводка, детальные баг-репорты и доказательства |
| `docs/Test-strategy.md` | Объём, подход, допущения и риски |
| `reports/Exploratory-run.md` | Краткий отчёт живого прогона от 2026-09-03 00:01 UTC |
| `reports/Newman-run.md` | Сводка полного Newman-прогона по 57 уникальным Test ID |
| `reports/newman-summary.json` | Машиночитаемый результат прогона без токенов и тел ответов |

## Покрытие и результат

- Тест-кейсов: **57**.
- Автоматизировано в Postman: **57**.
- В исследовательском прогоне: **33 пройдено**, **24 провалено**, **0 не выполнялось**.
- Подтверждённых дефектов: **9**.

## Запуск в Postman

1. Импортировать collection и environment из папки `postman`.
2. Выбрать окружение **Restful Booker — Public**.
3. Запустить всю коллекцию строго последовательно.
4. Не отключать служебные запросы `[SETUP]`: они создают уникальные фикстуры и сохраняют ID.
5. Папка `99 - Cleanup` удаляет только точные bookingid, которые коллекция сохранила при собственных успешных POST-запросах текущего запуска.

Проверки, связанные с открытыми багами, намеренно сравнивают ответы с ожидаемым контрактом. Пока дефекты воспроизводятся, соответствующие assertions будут красными — это ожидаемый результат тестирования, а не ошибка коллекции.

## Запуск через Newman

```bash
npm install
npm test
```

JSON-отчёт создаётся в `reports/newman-report.json`. Для формирования отчёта без ненулевого exit code:

```bash
npm run test:report
```

## Особенности стенда

Restful Booker — публичный общий тестовый сервис. Записи других пользователей, периодические сбросы и ранее сохранённые невалидные данные могут влиять на фильтры и ID. Поэтому коллекция:

- генерирует уникальные значения на каждый запуск;
- не использует предзагруженные ID;
- создаёт собственные фикстуры;
- проверяет изменения повторным GET;
- ведёт явный список созданных bookingid и выполняет безопасный cleanup только по этому списку.
